🤖 Ensemble ML Architecture

Three models combined for maximum detection accuracy, following Al-Shehari et al. (2023) IEEE Access methodology:

🌲 Random Forest
Supervised learning — trains on labeled normal/anomaly events. Like 100 judges voting on whether an event is suspicious. Majority vote wins. Detects patterns like "intern + CreateUser + 3AM = anomaly".
Formula: F(x) = (1/T)Σft(X) — Eq.3, Al-Shehari et al. (2023) p.118176
⚡ XGBoost
Gradient boosting — finds complex patterns Random Forest misses. Detects combinations like "same user + denied action × 5 in 2 minutes = brute force". More powerful on sparse, high-dimensional data.
Formula: F(x) = Σft(x) — Eq.2, Al-Shehari et al. (2023) p.118175
🌲 Isolation Forest
Unsupervised — finds anomalies WITHOUT labeled training data. Works by asking "how easy is it to isolate this event?" Rare events get isolated quickly = anomaly. Contamination = 0.02 (optimal: 98% accuracy, 99% F-score).
S(x) = c(n)·h(x)/T — Eq.6, Al-Shehari et al. (2023) p.118177 | Contamination=0.02, Table 6
📐 Trust Score Formula

Based on Jeong & Yang (2025) Applied Sciences 15(17):9551

TS = 0.4·B + 0.3·N + 0.2·D + 0.1·T
B = User Behavior (40%)
Login time, access patterns, off-hours activity
N = Network (30%)
IP reputation, country, VPN usage
D = Device (20%)
Device trust, patch status, authentication
T = Threat History (10%)
Past incidents, policy violations
Decision Thresholds
✅ ALLOWTS ≥ 0.80
⚠️ MFA REQUIRED0.60 ≤ TS < 0.80
🚫 BLOCK0.30 ≤ TS < 0.60
🔴 CRITICAL BLOCKTS < 0.30
Source: Jeong & Yang (2025), Section 4.1, Page 14
